# Prompt Collections

This is the collection of various prompts I use repeatedly for my work and side-projects.
Some of them related to system analysis, game design, and data preperation for RAG and more.

### Notes:
* Each markdown file is a standalone prompt. The recommended model to use is Claude Sonnet, but it should work well with ChatGPT and Gemini as well.
* The prompts could easily be converted into skills, as they are created for repeated use.

Feel free to use them and improve them.
Don't forget to share any interesting insights.
